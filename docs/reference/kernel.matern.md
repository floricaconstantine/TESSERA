# Matern Kernel Function.

Matern Kernel Function.

## Usage

``` r
kernel.matern(d, sigma2, rho, nu)
```

## Arguments

- d:

  Vector of distances.

- sigma2:

  Scale parameter.

- rho:

  Range parameter.

- nu:

  (kappa) Order of kernel.

## Value

A vector of covariance values.

## Note

Applies to a single area.
