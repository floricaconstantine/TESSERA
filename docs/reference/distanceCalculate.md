# Helper function for Moran's I.

Helper function for Moran's I.

## Usage

``` r
distanceCalculate(x1, y1, x2, y2)
```

## Arguments

- x1:

  First x-coordinate.

- y1:

  First y-coordinate.

- x2:

  Second x-coordinate.

- y2:

  Second y-coordinate.

## Value

Euclidean distance between (x1, y1) and (x2, y2).
