# Pre-processed TESSERA Data Object

An object of class `TESSERAData` (or the list format expected by the
package) generated by passing raw data through
[`prep_data()`](https://floricaconstantine.github.io/TESSERA/reference/prep_data.md).

## Format

A `.rds` file containing the processed TESSERA data structure, including
filtered counts and spatial weights formatted for the Leroux model.
