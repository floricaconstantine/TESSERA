# Exponential Kernel Function.

Exponential Kernel Function.

## Usage

``` r
kernel.exp(d, sigma2, rho)
```

## Arguments

- d:

  Vector of distances.

- sigma2:

  Scale parameter.

- rho:

  Range parameter.

## Value

A vector of covariance values.

## Note

Applies to a single area.
