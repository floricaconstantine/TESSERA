# Fitted TESSERA Leroux Model Object

A fitted model object resulting from running `TESSERA_lattice` on the
example prepared data.

## Format

A `.rds` file containing:

- beta_hat:

  Estimated fixed effects.

- tau2_hat:

  Estimated spatial variance.

- gamma_hat:

  Estimated spatial correlation (Leroux parameter).

- ...:

  Other tracked quantities.
