# The TESSERAData Class

The `TESSERAData` object is the primary data container for the `TESSERA`
package. Generated by
[`prep_data`](https://floricaconstantine.github.io/TESSERA/reference/prep_data.md),
it serves as the required input object for downstream model-fitting
functions, including
[`TESSERA_lattice`](https://floricaconstantine.github.io/TESSERA/reference/TESSERA_lattice.md)
and
[`TESSERA_spNNGP`](https://floricaconstantine.github.io/TESSERA/reference/TESSERA_spNNGP.md).
The object organizes multi-sample spatial data—-including coordinates,
metadata, count matrices, design matrices, and pre-computed spatial
neighborhood matrices and eigenvalues-—into structured, per-sample
lists. Pre-computing and storing static quantities (such as adjacency
matrices and graph Laplacian eigenvalues) within the `TESSERAData`
object accelerates downstream gene-by-gene model fitting across
thousands of genes without redundant computations.

## Elements

A `TESSERAData` object is a structured list containing the following
sample-indexed elements:

- **coords_list**: List of spatial coordinate matrices (measurements
  \\\times\\ spatial dimensions), one per sample.

- **covariates_list**: List of data frames containing sample metadata
  and cell-level covariates, one per sample.

- **counts_list**: List of count matrices (genes \\\times\\
  measurements), one per sample.

- **library_size_list**: List of numeric vectors representing sequencing
  depth/library sizes (offsets), one per sample.

- **X_list**: List of fixed-effect design matrices (measurements
  \\\times\\ parameters), one per sample.

- **W_list**: List of sparse binary adjacency matrices (measurements
  \\\times\\ measurements) for lattice models, one per sample.

- **D_list**: List of sparse diagonal degree matrices for lattice
  models, one per sample.

- **eig_CS_list**: List of pre-computed eigenvalues for CAR/SAR lattice
  covariance structures, one per sample (`NULL` if not computed).

- **eig_L_list**: List of pre-computed eigenvalues for Leroux lattice
  covariance structures, one per sample (`NULL` if not computed).
