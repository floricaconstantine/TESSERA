# Compute the Negative Hessian of gamma. ONLY APPLIES TO THE Leroux MODEL.

Compute the Negative Hessian of gamma. ONLY APPLIES TO THE Leroux MODEL.

## Usage

``` r
neg_hessian_gamma_Leroux(gamma_hat, eig_vals)
```

## Arguments

- gamma_hat:

  Parameter of interest: Estimate of correlation parameter.

- eig_vals:

  Eigenvalues of D - W.

## Value

Negative Hessian of gamma. Also called the observed information.

## Note

Applies to a single area.
